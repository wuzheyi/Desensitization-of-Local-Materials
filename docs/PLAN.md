# 尽调材料可逆脱敏 · 设计与实现状态

> 版本 **v1.0** · 2026-11-05 · M1 已完成并通过端到端验证

## 1. 已锁定的范围

| 决策 | 结论 |
|---|---|
| AI 润色 | **工具内不实现**，只做「导出脱敏稿 / 粘回润色稿」 |
| 数值脱敏 | **只做 A 模式（Token 化）**，不做保形缩放，不做勾稽校验 |
| 实体识别 | 规则 + 词表 + 别名扩展，**不接 NER 模型** |
| 文档格式 | `.docx` / `.txt` / `.md`；PDF、Excel 不做 |
| 关联标识 | 股票代码、域名、URL、邮箱、电话、地址、车牌、IP 全部纳入脱敏 |

## 2. 架构

```
src/core/            纯函数，零 DOM 依赖，全部可单测
  checksum.ts        身份证 GB11643 / 信用代码 / 银行卡 Luhn
  numeric.ts         数值识别（按形态分级放行）
  rules.ts           标识符识别（含股票代码、域名、地址）
  dict.ts            Aho-Corasick 多模式词表匹配
  alias.ts           简称抽取 + 去行政区/行业后缀生成别名
  overlap.ts         重叠裁剪
  detect.ts          检测流水线
  ledger.ts          实体归并、占位符分配、按行对齐切分
  restore.ts         容错还原 + 三类诊断
src/io/files.ts      文件解析（mammoth 懒加载）
src/components/      五步界面
```

数据流：`原文 → 候选命中 → 实体账本 → 占位符 → 脱敏稿 → (外部 AI) → 粘回 → 按账本还原`

## 3. 关键实现决策与理由

### 3.1 占位符设计

`〔类型_序号〕`，如 `〔机构_1〕`、`〔金额_2〕`。

- **全角方括号**：中文大模型几乎不改写这个形态（实测中仍会改，故还原必须容错）
- **带类型与序号**：AI 能理解「同一主体」，润色不跑偏
- **同一 canonical 共用**：全文指代一致

### 3.2 数值分级放行

误伤比漏脱更容易毁掉体验：一篇材料被切得七零八落，用户就会放弃工具。

| 形态 | 处理 |
|---|---|
| 带货币单位 | 必脱 |
| 带 `%` / `倍` / `bp` | 必脱 |
| 带人/家/股/户 等数量 | ≥ 100 才脱（`3 家子公司` 保留） |
| 无单位 | 有千分位或小数点且 ≥ 1000 才脱（`2023`、`3.2.1` 一律放过） |

### 3.3 单位一并进占位符

`1.85 亿元` → `〔金额_1〕`，单位不留在外面。

原计划是「单位保留在 Token 外，让 AI 知道量级」，实现时改为整体替换。原因：单位留在外面会让还原出现 `1.85亿元万元` 的双单位，要正确处理就得在账本里同时存数值本体和渲染模板，复杂度和出错面都变大。既然 AI 只做语言润色，放弃量级提示、换取「还原绝对逐字一致」是更划算的交换。

### 3.4 简称单独成实体

`深圳市前海云启科技有限公司（以下简称"云启科技"）` 中的全称与简称**各占一个占位符**，而不是共用一个。共用会让还原时把简称替换成全称，文本被改。语义上的「同一主体」提示因此丢失，这是为逐字还原做的取舍。

### 3.5 还原容错

AI 会改写占位符，实测形态包括 `【机构1】`、`(机构 1)`、`[机构_1]`、断行。

- 括号种类宽松：`〔〕 [] 【】 （） () ｛｝ 「」`
- 分隔符可选，空格也算
- 序号归一（`001` = `1`）
- 括号内多占位符可拆开分别还原
- 三类诊断：**缺失**（AI 删了）、**未知**（AI 编的）、**残留**（正文还剩占位符）

文号 `〔2020〕` 因不含「类型+序号」结构，不会被误判。

### 3.6 双栏按行对齐

两栏各自自由换行会导致行错位，逐行比对时极易看错。改为按原文换行切行，每行一对单元格，由 CSS 网格保证左右同高。鼠标选区通过每段的 `data-s` 绝对偏移换算回文本位置，而不是依赖 `Range.toString()`（后者在有块级元素时会插入换行，偏移会错）。

## 4. 验证结果

**单测 22 项全绿**，覆盖校验位、数值分级、标识符、简称、往返一致性、破坏性改写、缺失/未知诊断、文号不误判。

**端到端（无头 Edge 实跑）**：

| 检查项 | 结果 |
|---|---|
| 示例材料识别 | 21 个实体 / 22 处命中 |
| 脱敏稿 | 392 字，主体、金额、比例、代码全部替换 |
| 模拟 AI 改写（换括号 + 下划线变空格） | 还原后 **489 字，与原文逐字一致** |
| 占位符还原 | 22 处全部还原，无残留 |
| 手动补脱敏 | 选中文字标记后实体数 21 → 22 |
| 控制台异常 | 无 |

## 5. 已知边界

- 扫描件 PDF 不支持（无文本层）
- 导出为纯文本，不保留原文档样式
- 无 NER：人名、公司简称依赖词表与别名扩展
- 不加密本地产物（当前不落盘，刷新即清空）

3. **审计报告**：导出实体清单与人工修改记录
4. **PDF 文本层**：`pdfjs-dist` 抽取
5. **脱敏稿自检面板**：列出未覆盖的敏感类型，提示用户自查
6. **可选 NER**：Worker + ONNX，作为召回增强（不作为兜底）

## 7. 明确不做
